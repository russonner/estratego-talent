# CLAUDE.md — Estratego Talent

Instrucciones de comportamiento para todas las sesiones de este proyecto.

---

## Proyecto
Sitio web de Estratego Talent en `index.html`. Single-file HTML+CSS+JS.
- **Producción:** estratego.com.mx vía Vercel (auto-deploy al push a `main`)
- **Flujo:** editar → commit → push directo, sin pedir confirmación

---

## Reglas generales
- Hacer `git commit + git push origin main` automáticamente después de cada cambio aprobado
- Actualizar la sección "Historial de sesiones" del README.md al final de cada sesión
- No pedir confirmación para el push en este proyecto
- Todo el contenido del sitio en español, excepto la sección internacional que es bilingüe
